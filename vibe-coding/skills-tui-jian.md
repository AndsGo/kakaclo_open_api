# skills 推荐

1、Skill-creator

Anthropic 官方 Skill，用于制作 Skill 的元 Skill，可以帮你生成符合要求的 Skill，非常建议使用学习。

地址：[https://github.com/anthropics/skills/tree/main/skills/skill-creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator)

2、document-skills

Anthropic 官方 Skill，用于文档处理的 Skill，包含 docx、xlsx、pptx、pdf，可以根据用户需求生成不同类型的文档。功能并不复杂，适合研究以后制作更符合自己的 Skills

地址：[https://github.com/anthropics/skills/](https://github.com/anthropics/skills/)

3、frontend-design

前端设计能力的 Skill，能让 AI 生成的前端页面不那么一眼看出来就是 AI 生成的，设计感更高级。

地址：[https://github.com/anthropics/skills/tree/main/skills/frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)

4、SuperPowers

增强的计划模式，能够进行头脑风暴、计划拆分，使用子代理驱动开发，提高编码效率和效果。

地址：[https://github.com/obra/superpowers/](https://github.com/obra/superpowers/)

5、Agent-Skills

Vercel 官方发布的 Skill，主要和 React 相关的最佳实践、UI设计、vecel 部署相关操作

地址：[https://github.com/vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)

6、Planning with files

这个是复刻了 Manus 工作的流程，可以使用 md 文件去做计划、任务追踪、知识存储。

地址：[https://github.com/OthmanAdi/planning-with-files](https://github.com/OthmanAdi/planning-with-files)

7、UI-UX-Pro

专注于 UI、UX 设计的 Skill，集成了超过 67 种 UI 风格，96种颜色模式，57种字体，还有丰富的系统管理能力。

地址：[https://github.com/nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

8、Obsidian

Obsidian 官方推出的，可以高效的管理和理解你的 Obsidian知识库。

地址：[https://github.com/kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)

9、Remotion

可以使用 React 框架去创建视频，通过 CSS、SVG、WebGL 等内容以及变量、API、函数等等，能够创建出质量非常不错的视频，最近也是大火的 Skill。

地址：[https://github.com/remotion-dev/remotion](https://github.com/remotion-dev/remotion)
